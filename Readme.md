Image Content Viewer - Autopsy Plugin
==========================================

Image Content Viewer plugin module for Autopsy digital forensics platform.

Autopsy homepage: https://sleuthkit.org/autopsy/

Screenshot
----------

![Plugin Screenshot](/images/imagecontentviewer.png?raw=true)

Features
--------

* Colour Speace Analysis RGBG YCbCr
* Level Sweep
* Luminance Gradient
* PCA
* Thumbnail
* Noise
* Error Level Analysis
* Clone Detection
